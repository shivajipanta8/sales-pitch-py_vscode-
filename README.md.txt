# Sales Analysis Project

This project analyzes sales data using pandas and matplotlib.

## Requirements

Install dependencies with:

```
pip install -r requirements.txt
```

## Usage

Run the analysis script:

```
python sale_analysis.py
```

Optional arguments:

- `--data-file`: Path to the CSV dataset file. Defaults to `Sales_Data.csv`.
- `--output-file`: Optional text report output file.
- `--plot-dir`: Directory to save plot images. Defaults to `plots`.

## Output

The script prints a summary report to the console, optionally saves a text report, and generates plot images in the specified plot directory.
